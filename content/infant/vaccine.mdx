# 영아 백신

## 폐렴구균

소아에서 폐렴을 일으키는 세균중, 가장 치명적이고 흔한 세균으로 폐렴, 중이염, 세균성 수막염등을 일이킬 수 있습니다.

| 구분   | 프리베나20 | 박스뉴반스 |
| ------ | ---------- | ---------- |
| 회사   | 화이자     | MSD        |
| 백신주 | 20가 백신  | 15가 백신  |

프리베나20은 2021년 처음 18세 이상 성인을 대상으로 FDA에서 승인되었고, 2023년 영유아 및 소아까지 확대 승인되었습니다.  
박스뉴반스는 2021년 18세 이상 성인을 대상으로 FDA에서 승인되었고, 2022년 영유아 및 소아까지 확대 승인되었습니다.

박스뉴반스 보다 프리베나20이 더 커버리지가 넓기 때문에 프리베나20을 선호합니다.

## 로타바이러스

예전에는 감기나 폐렴, 열로 입원하는 아이보다 장염으로 입원하는 아이들이 많았다고 합니다.
그리고 그 장염의 대부분의 원인으로 로타바이러스 때문에 발생하는것으로 알려졌습니다. 하지만 로타바이러스 백신 덕분에 로타바이러스 장염 환자수가 크게 줄었습니다.

![로타바이러스 이미지](/rotavirus.jpg)
연도별 로타바이러스장염 환자수 추이 [단위:명](출처: 건강보험심사평가원 보건의료빅데이터개방시스템)[^1]

| 구분     | 로타텍                         | 로타릭스               |
| -------- | ------------------------------ | ---------------------- |
| 회사     | 한국MSD                        | GSK                    |
| 유래     | 사람-소 유래 로타바이러스      | 사람 유래 로타바이러스 |
| 백신주   | G1, G2, G3, G4, P1A (5가 백신) | G1P1A (1가 백신)       |
| 예방효과 | 96.8%                          | 90.4%                  |
| 접종     | 3회(2,4,6개월 접종)            | 2회(2, 4개월에 접종)   |

두 백신 모두 예방 효과가 비슷하기 때문에 접종횟수가 적은 로타릭스가 선호됩니다.
